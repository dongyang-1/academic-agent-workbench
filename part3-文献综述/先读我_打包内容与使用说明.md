# 文献综述 skill 转发包

整理日期：2026年10月18日。

## 可以直接发送什么

发送同名ZIP即可，接收方应解压并保留整个 `zotero-literature-review` 文件夹，不能只复制 `SKILL.md`，因为主文件会引用配套文件。

```text
文献综述skill_转发包_20261018/
├─ 先读我_打包内容与使用说明.md
├─ 文件清单与校验.json
└─ zotero-literature-review/
   ├─ SKILL.md
   ├─ agents/
   │  └─ openai.yaml
   └─ references/
      ├─ research-workflow.md
      ├─ deliverables.md
      ├─ zotero-word-integration.md
      └─ access-and-portability.md
```

## 文件各自做什么

| 文件 | 用途 | 是否保留 |
|---|---|---|
| SKILL.md | 入口、适用范围、证据约束、分阶段工作流程 | 必须 |
| research-workflow.md | 文献盘点、证据卡、观点矩阵、正式综述、研究评述和引用核验 | 必须 |
| deliverables.md | Word、Excel与格式规范，交付物之间的一致性 | 完整转发包保留；生成相应文件时使用 |
| zotero-word-integration.md | 通过真实Zotero Word插件创建和核验动态引文 | 完整转发包保留；动态引文任务时使用 |
| access-and-portability.md | 换电脑后的文献接入、附件读取与能力检查 | 新增，建议保留 |
| agents/openai.yaml | 支持此文件的工具可读取显示名称和默认提示词 | 保留；不支持它的工具可忽略 |
| 文件清单与校验.json | 文件大小、SHA-256、与原版是否一致 | 建议随包发送 |

## 接收方还需要准备什么

| 要完成的任务 | 接收方需要准备 |
|---|---|
| 文献盘点、分类、观点矩阵、文字综述、引用核验 | 能读取该skill的AI工具；自己的文献元数据和可访问原文；明确研究问题与文件夹范围 |
| 直接读取Zotero | 自己可用的Zotero连接器／API／本地读取能力，并允许访问目标文献库及附件；本包不自动安装连接器 |
| 没有Zotero连接器时继续工作 | 提供目标文件夹的文献导出及附件，保留条目对应关系和文件夹范围；具体可用字段取决于导出格式 |
| 阅读扫描版PDF | 可用的OCR和核对原文能力 |
| 生成Word或Excel | 可用的文档／表格生成、渲染和检查工具；若工具采用独立skill，需要另行准备相应skill |
| Word内可刷新Zotero引文 | Word桌面版、Zotero及其真实Word插件、目标文献库、适用CSL样式，以及实际操作和验证插件的能力 |
| 按学校或期刊规范排版 | 接收方适用的格式要求；有指定模板或CSL时另外提供 |

这是方法规则包，不能单靠解压就获得文献访问权限，也不包含其他软件的运行环境。本包没有可执行脚本，无需为skill本身运行安装命令。是否需要Python、PDF解析库或其他软件，由实际接入和交付方式决定。

## 如何使用

**已有skill加载功能的工具：**将完整技能文件夹交给该工具，按接收方工具的技能加载方式使用。文件夹扫描位置、自动发现和重启要求以其环境配置为准，本包不修改配置。

**只支持读取项目文件的工具：**将技能文件夹放在项目内，例如 `skills/zotero-literature-review/`，在任务提示词中明确要求读取主文件及其指定参考文件。这能传递规则，但不保证工具会自动发现skill。

**普通聊天环境：**如果工具允许读取附件，可以提供这些Markdown文件并要求先读取；仍须另行提供论文或文献库访问能力。仅粘贴技能名称无法传递完整规则。

可复制给接收方的首次提示词：

> 请先读取 `skills/zotero-literature-review/SKILL.md`，并按其中说明读取当前任务需要的参考文件。请核实我提供的Zotero接入或导出文件是否可用。研究主题是【填写】，目标文件夹是【填写】，是否包含子文件夹为【填写】，本次只需要【盘点／分类／观点矩阵／正式综述／异质性梳理／引用核验】，输出为【填写】。请区分全文、摘要和元数据证据，为重要结论标注原文位置。未经我允许，不扩展到文件夹之外的文献。

若工具支持按名称调用技能，也可使用 `$zotero-literature-review`，但应先确保它已经加载本包的实际文件。
