# 摘要（aer-abstract）

## 硬约束

- **≤ 100 词**（AER 作者指南明文要求，article / comment / reply 均需）。
- 与标题、署名、单位一起放在 PDF **第一页顶部**；不设独立 title page。
- 定稿**最后**写：识别或主结果一变，摘要就要重写。

## 100 词的分配

| 句子 | 内容 | 预算 |
|------|------|------|
| 1 | 经济学问题（不含国别包装） | ~20 词 |
| 2 | 识别：什么变异、什么设计 | ~25 词 |
| 3 | 主结果：**带数值与方向**的效应量 | ~30 词 |
| 4 | 机制/异质性或为什么重要（择一） | ~15 词 |
| 5 | 一句含义（谨慎，不喊口号） | ~10 词 |

## 写法要点

- 给**效应量**："…raises X by 12 percent (SE 0.03)" 优于 "…has a significant positive effect"。
- 用**动词**而非名词堆砌：identify / exploit / estimate / show。
- 不要出现：This paper studies… / fills a gap… / has important policy implications…（占词且无信息）。
- 不要出现未在正文定义的数据缩写与行业黑话。
- 时态：问题与结论用现在时，估计动作可用现在时或过去时，全篇一致。

## 自检

```
[ ] 词数 ≤ 100（用工具数，不要目测）
[ ] 含具体效应量与方向
[ ] 含识别来源（experiment / policy shock / instrument / design）
[ ] 没有"gap / enrich / important implications"
[ ] 与正文主规格的系数完全一致
```
