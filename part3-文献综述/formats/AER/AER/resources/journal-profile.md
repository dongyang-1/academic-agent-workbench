## 审稿模式

- **单盲**（referee 知道作者身份）。
- 提交后先经 **coeditor 桌筛**：评估经济学重要性、方法严谨性、题目广度与 AER 读者兴趣；按公开主编报告，2025 报告年度约 **39%** 初次投稿在此阶段被直接退回，通常一到两周内出结果，极少数超过一个月。
- 送审阶段平均约 **3 份**审稿报告（拒稿稿约 2.9 份，R&R 稿约 3.4 份）。
- 首次决定**不直接条件接受**；R&R 决定前会咨询第二位 coeditor。
- 有 **AEA transfer option**：被拒后可转投 AEJ: Applied / Macro / Micro / Economic Policy。

## 格式硬约束

- 摘要 **≤ 100 词**（article / comment / reply 均需），与标题、署名、单位同置首页。
- 稿件 PDF 不含独立 title page；标题与署名置于第一页顶部。
- 需要 **JEL 分类号**（通常 2-4 个）与关键词。
- 图表称 exhibits，按正文出现顺序编号引用。
- 接受后须遵循 **Chicago Manual of Style + AER Style Guide**，并提供原生排版文件。

## 合规与材料

- 每位合著者**单独**提交 PDF 披露声明：资助来源、其他潜在利益冲突、IRB 批准（涉人受试者时）；无内容也须正式声明"无"。
- 田野实验须提供 **AEA RCT 注册号**。
- 使用 AI 辅助须在稿件中简要说明。
- 含实证 / 模拟 / 实验的稿件：有条件接受后须提交数据与代码至公开可信仓储（AEA Data and Code Repository / openICPSR），附 README、签字的 Data and Code Availability Form 与 Data and Code Archive Agreement；数据专有须在**投稿时**告知主编。
- 可另附 Supplemental Appendix（单独 PDF，标题以 "Supplemental Appendix" 开头）与可选的展示幻灯片。

## 与本项目其他期刊包的定位差异

| | AER | 经济研究 / 管理世界 | 中国工业经济 / 金融研究 | 经济学(季刊) |
|---|---|---|---|---|
| 首要门槛 | 经济学重要性与广度 | 选题意义与现实关怀 | 实证工程化 / 金融识别 | 国际范式与识别规范 |
| 摘要 | ≤100 词英文 | 中文长摘要 | 中文摘要 | 英文摘要 ≤100 词 |
| 引用 | 作者—年份夹注 | 脚注/上标为主 | 各刊自定 | 页内夹注 + 3 个 JEL |
| 复现 | 强制数据包 | 逐步要求 | 逐步要求 | 逐步要求 |
