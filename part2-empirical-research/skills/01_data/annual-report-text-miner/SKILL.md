# 上市公司年报文本与词频挖掘爬虫 (Annual Report Text Miner)

## 一、 这个 Skill 是干什么的
`annual-report-text-miner` 专为经济学、管理学与金融学前沿的**“非结构化文本实证”**而打造。在传统财务数据库中，诸如“企业数字化转型程度”、“绿色低碳关注度”、“管理层短视”等核心构念无法直接查得现成数值。本 Skill 自动化抓取或解析上市公司年报（特别是“管理层讨论与分析 (MD&A)”章节），基于经管顶刊公认的词库体系，通过文本挖掘与分词统计，自动构建**绝对词频 (`count`)、顶刊对数平滑项 (`ln(count + 1)`) 及词频密度 (`density = count / total_words * 100%`)**，直接输出包含 `firm_id` 和 `year` 的标准微观计量面板，可直接与财务报表面板合并。

### 💡 核心底层逻辑与官方数据源（基于巨潮资讯网 CNINFO 直抓）
本功能并不是读取模拟数据，而是**直接穿透中国证监会法定披露平台进行真实年报爬取**：
1. **法定权威数据源**：
   - 对接中国证监会指定的上市公司信息披露门户——**巨潮资讯网 (CNINFO, cninfo.com.cn)**。
2. **底层自动化抓取与过滤链路**：
   - **精确公告检索**：根据股票代码与年份窗口向巨潮披露接口发送查询请求；
   - **智能排除噪音**：自动过滤排除“年报摘要”、“英文版”、“补充更正公告”等干扰文件，精准锁定真正的《XXXX年年度报告》全文；
   - **提取官方 PDF 直链**：自动解析出巨潮网底层静态存储直链（如 `http://static.cninfo.com.cn/finalpage/2024-03-27/1219412018.PDF`）；
   - **流式下载与校验**：流式下载真实官方 PDF（实测比亚迪 9.19MB、广汽 12.94MB 等），自动校验 `%PDF-1.x` 格式签名并落盘；
   - **章节解析与词频统计**：锁定“管理层讨论与分析 (MD&A)”章节，自动匹配经管顶刊标准词库完成指标计算。
3. **支持学术双重模式**：
   - **在线直抓模式**：指定股票代码与年份，全自动完成从巨潮网检索、下载到词频提取全流程；
   - **本地离线扫描模式**：若学者已从高校数据库（如 CSMAR / Wind）批量导出了年报 PDF/TXT，可直接指定本地文件夹进行秒级批量解析。

## 二、 什么时候使用
- 实证论文的核心解释变量或被解释变量为“企业数字化转型”、“绿色技术创新”、“ESG 环境关注度”或“管理层短视”；
- 需从文本中提取传统财务指标无法衡量的企业战略倾向与无形投入；
- 配合控制变量排查企业异质性。

## 三、 内置顶刊权威词库
1. **数字化转型词库 (Digital Transformation)**：
   - 参考文献：吴非等 (2021)《中国工业经济》、袁淳等 (2021)《中国工业经济》；
   - 涵盖底层技术（人工智能、大数据、云计算、区块链）与实践应用（数字孪生、智能制造、工业互联网、自动驾驶等）。
2. **绿色低碳与环保创新词库 (Green Innovation)**：
   - 涵盖低碳转型、节能减排、清洁生产、碳中和、循环经济、绿色技术等。
3. **管理层短视主义词库 (Managerial Myopia)**：
   - 基于时间视野理论，捕捉管理层在战略陈述中的短期功利导向词频。
4. **自定义扩展词库**：
   - 允许研究者传入特定研究主题的专属词表（如“出海与全球化”、“供应链安全”）。

## 四、 执行流程
1. **样本企业与年份输入**：指定目标股票代码池与考察年份；
2. **词库配置与匹配**：选择经典词库或自定义词表；
3. **文本指标计算**：
   - 原始词频：`raw_count`
   - 对数化变量：`ln_count = ln(raw_count + 1)`（缓解右偏分布）
   - 密度变量：`density_pct = (raw_count / total_words) * 100`（控制年报总篇幅干扰）
4. **融合微观财务面板并移交审计**：
   - 自动按 `(firm_id, year)` 与基础财务面板左连接（Left Join）；
   - 移交 `L1: data-audit` 执行实证结构审计。
