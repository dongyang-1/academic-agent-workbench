- 不要把 API key 写进任何 markdown、json、yaml 或脚本文件。

- 后续脚本读取环境变量；如果缺失，则应停止真实 API 请求并提示配置。

## 团队合并时需要统一的约定

- 所有模块使用英文小写连字符作为 id，例如 `literature-search`。
- 所有模块输出 JSON 时保留 `module_id`、`version`、`created_at`。
- 所有事实性内容必须有来源字段或标注 `needs-check`。
- 文献检索模块只交付候选文献和检索证据，不替代后续模块做最终综述判断。
