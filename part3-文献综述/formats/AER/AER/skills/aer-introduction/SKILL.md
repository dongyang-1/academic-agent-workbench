# 引言（aer-introduction）

## AER 引言的任务

coeditor 在几分钟内判断**重要性与广度**。引言前两页必须回答：

1. 这个经济学问题为什么重要（对非本 field 读者也要成立）；
2. 为什么此前没被可信地回答（是设计/数据/变异的困难，不是"没人做过"）；
3. 本文用什么变异解决它；
4. 发现什么，以及相对**具体哪几篇**文献推进了什么。

## 结构（建议 4 段）

| 段 | 内容 | 篇幅 |
|----|------|------|
| 1 | 一般性经济学问题 + 为什么重要 + 为什么难识别 | ~3/4 页 |
| 2 | 本文的检验场与识别：什么外生变异、什么数据 | ~1 页 |
| 3 | 主结果 + 机制/异质性（带数值） | ~1 页 |
| 4 | 贡献对标（点名 2-4 篇）+ 与同期工作关系 + 全文路线 | ~1/2 页 |

## 贡献怎么写

- **对标到具体论文**："Relative to A (2020), who estimate … using …, we …"——说明你多做了什么（更干净的变异、更一般的机制、可外推的设定）。
- 禁止："填补了空白 / 丰富了相关研究 / 首次研究"。
- 若与同期 working paper 撞题，**主动写**：说明差异，不要等审稿人指出。
- 遇到"这只是 local 场景"的质疑，正面回答外部有效性：给出可外推的理由或边界条件。

## 语言

- 主动语态，短句；段落首句给出该段结论。
- 引用用作者—年份，正文夹注；参考文献按 AER Style Guide（Chicago 底子）。
- 需要 2-4 个 **JEL 分类号**（与关键词一起放在首页）。

## 自检

```
[ ] 第一页内出现经济学问题（非国别介绍）
[ ] 识别来源在第二页前讲清楚
[ ] 主结果带数值出现在引言
[ ] 至少点名 2 篇具体文献做对标
[ ] 无"gap / enrich / first to" 表述
```
