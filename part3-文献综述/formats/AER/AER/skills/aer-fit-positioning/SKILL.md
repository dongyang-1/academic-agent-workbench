# 适配性与定位（aer-fit-positioning）

## 触发时机

- 犹豫"投 AER 还是 AEJ / field journal"
- 刚被 summary reject，想判断是不是定位问题
- 课题来自中国情境，不确定国际读者是否关心

## AER 的门槛与中文刊不同

AER 的第一次筛选发生在**主编/coeditor 桌上**，判断的是三件事：

1. **Economics significance** —— 结果是否改变我们对某个经济学问题的认识；
2. **Breadth** —— 是否超出一个小 field，能引起一般经济学读者兴趣；
3. **Audience interest** —— AER 读者会不会愿意读。

按公开的主编报告口径，初次投稿中有相当比例（2025 报告年度约 39%）在这一阶段被直接退回，且通常在**一到两周内**出结果。因此：**不要拿"识别干净 + 稳健性做满"当投 AER 的理由**——那是必要条件，不是充分条件。

## 自评清单（逐条打分，任一为否 → 考虑 AEJ:Applied / AEJ:Policy 或 field top）

| 维度 | 通过标准 |
|------|----------|
| 重要性 | 能说清"如果这篇是对的，谁要改变做法/看法" |
| 广度 | 非专业读者能在引言前两段明白为什么值得关心 |
| 增量 | 相对具体 2-3 篇 field 文献有明确推进，而非"补充了实证证据" |
| 外部有效性 | 结论不止于一个狭窄制度场景（或明确论证为何该场景本身重要） |
| 设计 | 有可信识别：实验、准实验、结构，或极强的制度细节 |

## 中国情境怎么写才不被当成"local curiosity"

- **不要**把"中国首个/首个来自中国的证据"当卖点。
- **要**把中国制度当作**识别机会或一般机制的检验场**：说明它为何能回答一个别处回答不了的问题（规模、外生冲击、政策变异、数据可得性）。
- 引言第一段就给出那个一般性经济学问题，中国场景放第二、三段作为**检验场**出现。

## 转投路径

被拒后可选择 **AEA transfer option** 转至 AEJ 系列（AEJ: Applied / Macro / Micro / Policy）。写 R&R 或转投时不要重复 AER 审稿人的全部意见，聚焦重要性判断。
