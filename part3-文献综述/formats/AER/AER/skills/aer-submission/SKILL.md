# 提交与返修（aer-submission）

## 提交材料清单（缺件 = 不送审）

| 材料 | 要求 |
|------|------|
| 稿件 PDF | 含正文、图表、参考文献、附录；**不要单独 title page**，标题与署名置首页顶部；摘要 ≤ 100 词 |
| 披露声明 | **每位**合著者单独 PDF，页首写论文标题与作者名：资助 / 利益冲突 / IRB；无亦须声明 |
| RCT 注册号 | 田野实验须给 AEA RCT 注册号 |
| AI 使用说明 | 稿件中简述 |
| 附信 | 可选，但建议用；一页内说明贡献与适配性 |
| 数据/代码 | 有条件接受后提交（见 `aer-data-availability`） |

排版：投稿阶段 PDF 即可，AEA 模板可选；**接受后**须符合 Chicago Manual of Style 与 AER Style Guide，并提供用于生成 PDF 的原生文件（LaTeX / Word / Scientific Word）。

## 流程与节奏

提交 → coeditor 桌筛（重要性与广度，快速，通常数周内）→ 送审（单盲，平均约 3 份报告）→ 决定（拒稿或 R&R；R&R 前会咨询第二位 coeditor）→ R&R 可多轮 → 有条件接受 → 数据编辑核验复现包 → 出版协议。

材料齐备最重要：披露、摘要长度、首页格式这类"行政项"被挑会直接退回。

## R&R 回复信写法

- 逐条回应，按**审稿人 × 意见编号**组织；先给"做了什么"，再给"在哪里改"（页码/行号/表号）。
- 区分 **essential**（必须做）与 **optional**（可解释为何不做）。
- 无法做的意见，说明原因并给出替代证据，**不要沉默跳过**。
- 附一份"变更清单"，便于编辑核对。
- 被拒时可考虑 AEA transfer option 转投 AEJ 系列。

## 自检

```
[ ] 首页：标题 + 署名 + 单位 + ≤100 词摘要
[ ] 每位作者单独披露声明
[ ] 摘要词数已用工具核过
[ ] 图表编号与正文引用顺序一致
[ ] 实验有 RCT 注册号；用了 AI 已说明
[ ] 复现包可跑通（接受阶段）
```
